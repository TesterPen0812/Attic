Built from Claude's gap sheet, not yet reviewed by the owner. This is a source-only handoff on `iphone/build-settings`; the Stage 4 visual/test gate remains with the lead after integration.

- Integrate `PhoneSettingsPage()` as pushed content; the shell owns Back. It supplies System / Light / Dark, Lively / Subtle / Reduced, actual bundle version/build, and Mac About's GitHub link, using plain rows, Dynamic Type and named native controls.
- `PhoneLocalPreferences` uses only `AtticMobile.local.appearance.v1` and `AtticMobile.local.animations.v1` via AppStorage. Defaults: System and Lively. Unknown values fall back without migration. Tests inject synthetic defaults suites.
- Apply `.phoneLocalPreferences()` outside the shell's navigation and sheet modifiers so choices persist throughout the UI after Settings closes. System Reduce Motion forces Reduced without changing storage. The modifier adapts explicit animation transactions using Mac's spatial springs and exports `EnvironmentValues.phoneAnimationLevel`. Descendant `.animation(_:value:)` modifiers should use `phoneAnimationLevel.animation` to avoid overriding the selected spring. Reduced also suppresses implicit animations.
- Replace Home's generic menu with `PhonePageActionsMenu(menu: .home(openSettings: openSettings))`, supplying a real routing handler. Optional `editTags:` appears only when connected. Other pages supply `PhonePageMenu(pageTitle:actions:)` with stable IDs, current selection and live handlers. Empty menus disappear; destructive roles, selected checkmarks, 44 pt targets and Reduce Transparency are supported. Existing note/canvas menus retain their specialized controls.
